# Submission draft

## Product
OSI · House Management Operating System

## One-line description
A shared workspace for condominium communities to manage repairs, inspect spending and document collective decisions.

## Problem
Residential building management can fragment across chats, financial spreadsheets and paper documents. OSI tests whether a visible workflow helps residents and managers follow issues through to outcomes. The scale and severity of the problem still require customer interviews.

## What we built
A deployed browser-local prototype with request tracking, sample budgets, CSV export, demo voting, a maintenance view, documents and an event log. SHA-256 snapshots contain the exact payload needed for independent byte-level comparison.

## Blockchain integration
Not implemented in this release. Next experiment: anchor a protocol hash on Solana devnet and verify it via the transaction receipt. This would establish a public commitment to specific bytes, not legal validity, owner identity or proof that work was completed.
