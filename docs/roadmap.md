# Roadmap

## Implemented prototype

- [x] Request creation, search and status changes
- [x] Sample financial ledger and exports
- [x] Local demo polls
- [x] Maintenance and documents
- [x] Local journal and SHA-256 snapshots
- [x] Responsive interface

## Proposed 90-day plan

- Days 1–15: 10 owner/manager interviews and baseline workflow observation.
- Days 16–30: shared database, authenticated building access and a real devnet hash receipt.
- Days 31–60: seek 3 building pilots and measure weekly use.
- Days 61–90: test paid continuation and define the next release from observed behavior.

Dates are planning ranges, not commitments. Success target: 2 of 3 pilots choose to pay. Stop or change the offer if none pays after two iterations. A shared backend and identity checks are prerequisites for real pilots.

## Deferred

Legally binding voting, banking, custody, mainnet payments, automatic contractor payouts, AI decisions and tokenization.
