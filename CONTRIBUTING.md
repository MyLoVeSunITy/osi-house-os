# Contributing

Run `npm test` before proposing a change. Keep the demo runnable without secrets. Clearly label proposed functionality. Never commit resident data, credentials, keys, fabricated transactions or invented performance/customer metrics.

Keep request data escaped when rendering. Preserve the exact snapshot string when verifying SHA-256. Treat role switching as a demo control until server-side access control exists.

Provide a short description of the user problem, changed behavior and relevant verification with each contribution.
